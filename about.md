# Global List Integration
This mod brings the <cy>core features</c> of [<cj>demonlist.org</c>](https://demonlist.org) to GD.

## Mod Features:
- A <cg>button</c> in the level search screen that opens the <cj>demonlist</c>
- <cc>Search levels</c> by name or ID on the demonlist screen
- <cc>Filter levels</c> by difficulty, length, rating, and more
- <cc>Level placements</c> from the <cj>demonlist</c> displayed next to level info
- <cc>Leaderboards</c> with player search, country selection, and leaderboard type selection
- <cc>Detailed information</c> about users and countries in dedicated popups
